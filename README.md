# Retro Manga Serializer 🎨

> 一个开源的 AI Agent Skill：将故事与原创角色一键转化为 90 年代复古水彩手绘连载漫画。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## ✨ 特性

- 📼 **90 年代复古水彩美学**：告别千篇一律的现代 3D/数码厚涂，还原墨线手绘、水彩晕染与泛黄纸质感。
- 🎭 **跨媒介角色一致性**：支持将 3D 盲盒/黏土玩偶、真人形象转换为 2D 手绘漫画主角，并保持服装与配饰高度统一。
- 💬 **全简体中文排版**：严格规范生图过程中的旁白框、气泡对话及拟声字为简体中文。
- 🔄 **交互式多页连载工作流**：支持“单页生成 ➔ 用户确认 ➔ 下一页续连”的递进式创作机制。
